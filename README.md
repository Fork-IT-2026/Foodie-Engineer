# Flavorytics 🍽️✨

Flavorytics is an AI-powered healthy ingredient substitution platform that helps users replace unhealthy ingredients without compromising taste.

The system uses flavor compound analysis and computational gastronomy concepts to suggest scientifically matched healthy alternatives.

Built for the **Foodoscope ForkIT Challenge 2025 – IIIT Delhi**.

---

# 🚀 Features

- 🤖 Conversational AI cooking assistant
- 🍳 Recipe recommendation system
- 🥗 Healthy ingredient substitution
- 🧪 Flavor compound matching
- ❤️ Diet-aware recipe transformation
- ⚡ Interactive and modern UI
- 📊 Flavor match scoring system

---

# 💡 Problem Statement

People often struggle to replace unhealthy ingredients due to:
- Health concerns
- Dietary restrictions
- Allergies
- Ingredient unavailability

Most existing platforms provide generic substitutions without preserving taste and flavor integrity.

Flavorytics solves this using:
- FlavorDB
- RecipeDB
- AI-powered recommendation logic

to provide smart and healthy ingredient alternatives.
